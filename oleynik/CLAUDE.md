## ⚠️ ВСЕГДА
- **Перед вёрсткой прочитай `DESIGN.md` целиком** — палитра, шрифты, компоненты, тон, do/don't.
- Цвета/шрифты/отступы — только из `DESIGN.md`. Не «на глаз».
- Финал = ОДИН самодостаточный статический `.html` под контракт GetCourse (ниже).
- Публиковать через коннектор `gcpublisher` c `upload_images=true`.

## ❌ НИКОГДА
- Не выдумывай цвета вне палитры; алый `#E20110` — точечно (CTA, 1 акцентное слово), не заливка экрана.
- Не используй React/JSX/Babel для GC — только статический HTML, контент виден без JS.
- Не вешай кастомный JS на кнопки заказа кроме od-forms (ниже). Анимации — CSS-only.
- Не используй base64-картинки, локальные `assets/`, CSS `url()`-фоны.
- **Без эмодзи** — премиальный сдержанный тон; вместо них фирменная графика (шёлк, волны, мазки).

## 🔴 Картинки и публикация (соблюдать строго)
- **Контент-фото** (героиня, отзывы/аватары, автор) загружаются в Claude Design.
  При публикации коннектор сам заливает их в медиатеку GetCourse, получает
  **постоянную ссылку GetCourse** и подставляет её в сохранённый лендинг —
  фото на проде не протухают, хостинг берёт на себя GetCourse.
- В разметке фото — теги `<img src="…">`; коннектор перезаливает только `<img>`.
- Публиковать всегда с `gc_publish_landing(..., upload_images=true)`.
- **Бренд-ассеты** (логотипы, шёлк, волны, мазки) — постоянные raw-ссылки:
  `https://raw.githubusercontent.com/kadyninconstantin-lab/brand-systems/main/oleynik/assets/<file>.png`
- ❌ НЕ использовать base64-картинки и CSS `url()`-фоны — их коннектор не перезаливает.

## Кнопки заказа (od-forms)
- Первым в `<body>`: `<script id="od-forms" type="application/json">{"tariff":""}</script>` (коды `b-XXXXX` пустыми — впишет человек в редакторе GC).
- На кнопке тарифа: `data-od-form="tariff"`. Общие кнопки — якорь `href="#pricing"`.
- В конце `<body>` — делегированный слушатель, вызывающий `ltShowModalBlock(code)`.
- Стили кнопок — инлайн / высокая специфичность (базовый CSS GetCourse перебивает классы).

## Даты (вебинары/старты)
- `data-gc-date="2026-..-..T..:.." data-gc-tz="Europe/Moscow"` + inline-скрипт локализации. Не хардкодить «через N дней».
