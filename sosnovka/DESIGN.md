# Design System — Академия ландшафтного дизайна «СосновКа»

> Category: онлайн-образование, ландшафтный дизайн (b2c, женская аудитория 40–60, RU-speaking)
> Тёплая природная система: земляные коричневые нейтрали, глубокий хвойный зелёный и терракота
> на песочном фоне. Настроение — «сад в золотой час», уют и рукотворность, а не корпоративность.
> Это НЕ SaaS-минимализм на чистом белом, НЕ люксовый глянец и НЕ кричащий инфобиз.
> Источник истины: https://landscape-use.ru (значения извлечены из rendered CSS живого сайта
> 2026-08-17, не подобраны на глаз). Второй источник контента: https://guru-landshafta.ru

## 0. How to use this brief

- Это полная дизайн-система бренда «СосновКа». Следуй ей строго.
- Используй ТОЛЬКО цвета из палитры (секция 2) и шрифты из секции 3. Не выдумывай новые hex.
- Дефолтный фон — песочный `#F5F1E6` или белый, НЕ чистый серый и НЕ тёмная тема.
- Основной текст — коричневый `#4E3816`, не чёрный. Чёрный допустим только в мелких подписях.
- Первичная кнопка — тёмно-зелёная `#07351A`, вторичная — терракотовая `#CF813F`, радиус 12px.
- При конфликте «красиво vs бренд» — выбирай бренд.
- Соблюдай anti-patterns (секция 8): перечисленное не генерировать никогда.

## 1. Visual Theme & Atmosphere

Доминирует **фотография сада** — крупная, тёплая, с золотым контровым светом. Типографика
служебна: она подписывает картинку, а не спорит с ней. Фон — песочный кремовый, создающий
ощущение бумаги/льна, поверх него панели и карточки. Цвет используется точечно: зелёный
и терракота как две кнопки-антагониста, салатовый — только на крупных цифрах-нумерации.

Материальность: матовая, без глянца, без стекла и блюра. Скругления мягкие, но небольшие (12px).
Границ почти нет — блоки разделяются фоном и воздухом, а не линиями.

- **Tone words**: тёплый, природный, домашний, ухоженный, рукотворный, неспешный, женственный.
- **Avoid**: неоновые и кислотные градиенты, pure-white SaaS-минимализм, Inter/Roboto/системный
  шрифт, тёмная тема, glassmorphism, синий и фиолетовый в любых оттенках, стоковые улыбающиеся
  люди в офисе, иконки-линии в стиле enterprise-дашборда.

Частота = число элементов с этим значением в computed styles landscape-use.ru — уровень доверия.

### Пастельные подложки (второстепенные, для блоков-бонусов)

`#FFEED8` — кремовая, `#EAFFCE` — светло-салатовая. Использовать редко, максимум один блок
на экран, иначе страница рассыпается на пятна.

### Quick reference (for prompts)

Фон `#F5F1E6` · поверхность `#DED7C1` · текст `#4E3816` · первичный акцент `#07351A` ·
вторичный акцент `#CF813F` · декоративная зелень `#96AE66`.

## 3. Typography

### Families

- **Display / Headings / Body — `TildaSans`.** Основной шрифт всей системы: нейтральный
  гуманистический гротеск, спокойный, без характера — и это правильно, характер даёт фотография.
- **Accent — `Qanelas`.** Геометрический гротеск, применяется точечно: имя спикера, крупные
  цифры-нумерация (87px/700), часть кнопок. Не пускать в основной текст.

### Подключение

Оба шрифта уже отдаются публичным CDN Tilda. Qanelas — коммерческий, файл в репозиторий
не кладём, только ссылка:

```css
@font-face { font-family:'Qanelas'; font-weight:300;
  src:url('https://static.tildacdn.com/tild3637-6462-4135-b335-373736623338/Qanelas-Light.woff') format('woff'); }
@font-face { font-family:'Qanelas'; font-weight:400;
  src:url('https://static.tildacdn.com/tild3235-3465-4361-b133-663931643036/Qanelas-Regular.woff') format('woff'); }
@font-face { font-family:'Qanelas'; font-weight:500;
  src:url('https://static.tildacdn.com/tild3165-3564-4434-b430-373735396133/Qanelas-Medium.woff') format('woff'); }
@font-face { font-family:'Qanelas'; font-weight:600;
  src:url('https://static.tildacdn.com/tild3062-3866-4037-a237-366338313936/Qanelas-SemiBold.woff') format('woff'); }
@font-face { font-family:'Qanelas'; font-weight:700;
  src:url('https://static.tildacdn.com/tild3136-3336-4261-b561-396161373138/Qanelas-Bold.woff') format('woff'); }
```

TildaSans: `https://static.tildacdn.com/css/fonts-tildasans.css`

**Фолбэк, если внешние шрифты не подгружаются** — Google Fonts Manrope, геометрия и пропорции
близки к обоим:
`https://fonts.googleapis.com/css2?family=Manrope:wght@300;400;500;600;700&display=swap`

Стек: `font-family: 'TildaSans', 'Manrope', Arial, sans-serif;`

### Weight scale

Реально используются 300 / 400 / 500 / 600 / 700. Веса 800+ не применять — на сайте их нет.
300 работает как «воздушная» подпись под цифрой-фактом («выпускников по всему миру»).

### Type scale (fluid)

| Уровень | clamp() | Назначение | Источник |
|---|---|---|---|
| display-num | `clamp(3rem, 6vw, 5.44rem)` | Крупные цифры-нумерация, Qanelas 700 | 87px |
| h1 | `clamp(2rem, 4.5vw, 3rem)` | Первый экран | — |
| h2 | `clamp(1.75rem, 3vw, 2.5rem)` | Заголовки секций | 40px |
| h3 | `clamp(1.375rem, 2.2vw, 1.875rem)` | Подзаголовки, «1 день курса» | 30px |
| lead | `1.25rem` | Лид-абзац, ключевые пункты | 20px |
| body | `1.125rem` | Основной текст | 18–19px |
| caption | `1rem` | Кнопки, подписи, мелкое | 16px |

Межстрочный интервал крупных заголовков щедрый — **1.5–1.55** (40px → 62px, 30px → 44–47px).
Это часть характера: текст дышит, не сбивается в плотный блок. Body — 1.4 (18px → 25px).

### Spacing & rhythm

Базовый шаг 8px. Вертикальные отступы секций 96–120px на десктопе, 56–64px на мобильном.
Внутренние отступы карточек 24–32px.

## 4. Components

**Buttons.** Высота 48–56px, padding 16px/32px, `border-radius: 12px`, размер 16px, вес 600–700.
- Primary: фон `#07351A`, текст белый. Hover — затемнение до `#05280F`.
- Secondary: фон `#CF813F`, текст белый, часто в `text-transform: uppercase`. Hover — `#B86F31`.
- Ghost: прозрачный фон, рамка 1px `#CF813F`, текст `#CF813F`.
- Focus: `outline: 2px solid #96AE66; outline-offset: 2px`.
- Disabled: `#DED7C1`, текст `#4A3C27` при opacity .6.

Две кнопки рядом (разные слоты времени эфира) — штатный паттерн бренда, а не ошибка: первичная
зелёная и вторичная терракотовая стоят парой.

**Cards.** Фон `--surface` или белый, radius 12–16px, padding 24–32px, без рамки. Карточка
поверх фотографии — белая с лёгкой тенью (секция 6).

**Inputs.** Высота 48px, radius 12px, фон белый, рамка 1px `#DED7C1`, placeholder `--text-muted`,
focus — рамка `#07351A`.

**Badges / бейджи на фото.** Небольшая плашка `--surface-alt` с radius 8px, текст 14–16px
вес 600 цветом `--text`. Основной сценарий — подпись к работе ученицы.

**Numbered list.** Фирменный приём: крупная цифра Qanelas 700 цветом `--brand-leaf` слева,
текст 18px рядом. Цифры — единственное место, где салатовый берётся крупным пятном.

## 5. Layout Rules

- Контейнер `max-width: 1200px`, боковые поля 24px (мобильный 16px).
- Сетка 12 колонок, gap 24px. Карточки чаще по 2–3 в ряд.
- Первый экран: фотография на всю ширину, поверх неё слева — вертикальная панель `--surface`
  с оффером и кнопками. Это узнаваемая композиция бренда.
- Выравнивание текста — по левому краю. Центрируются только заголовки секций и CTA-блоки.
- Плотность средняя: воздуха много, но не разреженный лендинг-однослов.
- Фотография всегда крупная. Продукт про визуальную красоту — мелкие превью-миниатюры убивают
  главный аргумент.

## 6. Elevation System

Тени тонированы коричневым, а не чёрным — иначе система холодеет.

- Level 0: без тени (секции, плоские блоки).
- Level 1 (карточки): `0 2px 8px rgba(78, 56, 22, .08)`.
- Level 2 (карточка поверх фото, форма): `0 8px 24px rgba(78, 56, 22, .14)`.
- Level 3 (модалка): `0 16px 48px rgba(78, 56, 22, .2)`.
- Затемнение фото под текстом: `rgba(0, 0, 0, .6)` — реально используется на сайте.

## 7. Responsiveness

Desktop-first по происхождению (Tilda zero-block, артборд 1200px), но верстать mobile-first.

- Брейкпоинты: 480 / 768 / 1024 / 1200.
- < 768: сетка в одну колонку, боковая панель первого экрана уходит под фото на всю ширину.
- Типографика по `clamp()` из секции 3, отдельные media-переопределения не нужны.
- Кнопки на мобильном — на всю ширину контейнера, пара кнопок ставится столбиком с gap 12px.
- Аудитория 40–60 лет: минимальный размер текста 16px, тач-цели не меньше 48px.

### Anti-patterns (НЕ генерировать)

- Любые hex вне палитры секции 2. Особенно синий, фиолетовый, чёрный как цвет заголовков.
- Inter, Roboto, Open Sans, системный шрифт — типографика узнаваема, подмена ломает бренд.
- Тёмная тема, glassmorphism, blur-подложки, неоновые градиенты, 3D-иллюстрации.
- Чёрные тени `rgba(0,0,0,…)` под карточками — только коричневые тонированные.
- Стоковые улыбающиеся люди, офисы, рукопожатия, ноутбуки на белом фоне.
- Мелкие превью фотографий садов. Фото — главный аргумент, оно всегда крупное.
- Счётчики обратного отсчёта, «осталось N мест», мигающие таймеры. Они есть на текущем
  российском лендинге, но в новую систему не переносятся: на автовебинаре с почасовыми
  запусками ложный дефицит самоопровергается.
- Конкретные суммы дохода («от 120 000 ₽/мес») в макетах. Для рекламы Meta это блокер
  модерации; в дизайн-макетах не использовать даже как placeholder-текст.
